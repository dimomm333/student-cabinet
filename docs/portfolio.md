# Портфолио студента

В разделе `/dashboard/portfolio` студент создаёт, просматривает, редактирует и удаляет собственные достижения. Запись доступна сразу после сохранения. Фильтры используют категорию и год даты достижения. Записи без даты видны в списке за все годы. Счётчики отражают всё портфолио: проекты определяются по категории, награды — по отметке «Достижение отмечено наградой».

## Проверка деканатом

В карточке можно отправить достижение на проверку. Очередь `/deanery/portfolio` содержит отправленные записи в пределах действующих назначений `DeaneryDepartmentAssignment` на подразделения учебных групп студентов. Проверка назначения применяется при чтении очереди, выдаче файлов и принятии решения. После принятия решения запись исчезает из очереди. При отклонении студент видит причину и может отправить запись повторно.

Изменение сведений или вложений возвращает запись к самостоятельному статусу и снимает её с проверки или сбрасывает уже выданное подтверждение. Сохранение без изменений сохраняет статус. Решения сотрудников записываются в `PortfolioDecision` с указанием проверенной версии. История хранится до удаления достижения.

## Файлы

Для достижения доступны до 8 вложений общим размером до 32 МиБ. Отдельные лимиты — 20 МиБ для PDF и 8 МиБ для JPEG, PNG и статических WebP. Сервер сопоставляет MIME, расширение и содержимое, декодирует и перекодирует изображения и проверяет структуру PDF существующим валидатором «Услуг».

`PORTFOLIO_STORAGE_DIR` задаёт закрытый каталог (по умолчанию `.local/portfolio-documents`). В production используйте постоянный том с доступом только у приложения и включите его в резервное копирование вместе с SQLite. Лимит тела запроса на обратном прокси должен пропускать до 32 МиБ и 64 КиБ служебных данных формы. Привязки файлов и изменения записей сохраняются одной транзакцией Prisma. При удалении доступ прекращается с удалением метаданных, затем сервер удаляет файл с диска. Ошибка физической очистки записывается как `portfolio.storage_cleanup_failed`. Для ручной очистки при остановленном приложении сопоставьте имена файлов в закрытом каталоге с `PortfolioAttachment.storageKey` в согласованной копии БД.

## Миграция и проверки

Миграция `20261122140000_portfolio` добавляет три таблицы и индексы. При обновлении существующей SQLite остановите запись, сделайте согласованную резервную копию и сначала выполните `npm run db:deploy` на отдельной копии. Проверьте сохранность прежних данных и целостность SQLite, затем задайте рабочий `DATABASE_URL` и выполните `npm run db:deploy`. Заполнение демоданными для портфолио не требуется.

`npm run build` и `npm run test:portfolio` запускают целевую проверку с Chrome, отдельной SQLite и закрытым каталогом в `.local`. Для Edge задайте `PLAYWRIGHT_CHANNEL=msedge`. Сценарий покрывает операции с записями, фильтрацию, вложения, отсутствие и отзыв полномочий, решения деканата, обе темы и ширины 346, 360, 390, 768 и 1366 px.
