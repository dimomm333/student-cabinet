# Настройка общежития и работа сотрудника

## Подготовка

1. В кабинете администратора откройте **Общежития → Создать общежитие**. Укажите название, адрес и контакты коменданта.
2. В **Жилой фонд → Добавить комнату** укажите этаж, номер, тип и вместимость. Заполните корпус и блок там, где они используются. Система создаст отдельные места. Укажите недоступные места через карточку комнаты.
3. В **Назначения** введите email сотрудника и выдайте нужные полномочия. Для коменданта обычно нужны «Заселение и выселение» и «Управление ремонтом». «Выполнение ремонта» выдаётся назначаемому исполнителю. Доступ к начислениям, документам и публикациям выдаётся отдельно.
4. Выполните `npm run db:services:seed` для регистрации версий услуг. Для каждого исходного учебного подразделения настройте обработку `dorm-move-in` и `dorm-transfer` существующей командой `npm run services:configure -- <путь-к-файлу>`. Для сотрудника деканата сначала проверьте назначение на учебное подразделение.

Формат конфигурации маршрутов услуг. Подставьте реальные идентификаторы из действующей учётной системы и храните файл вне Git.

```json
{
  "routes": [
    { "serviceCode": "dorm-move-in", "sourceDepartmentId": "source-id", "departmentId": "processor-id", "active": true },
    { "serviceCode": "dorm-transfer", "sourceDepartmentId": "source-id", "departmentId": "processor-id", "active": true }
  ],
  "grants": [
    { "userId": "operator-id", "departmentId": "processor-id", "serviceCode": "dorm-move-in", "active": true, "readFiles": true, "readMilitary": false },
    { "userId": "operator-id", "departmentId": "processor-id", "serviceCode": "dorm-transfer", "active": true, "readFiles": true, "readMilitary": false }
  ]
}
```

5. В **Начисления → Настройки оплаты** задайте внешний HTTPS-адрес. Для изолированного показа подходит `https://example.com/`. Пустое значение скрывает кнопку перехода у студента.

В поле «Сумма, ₽» введите, например, `1500`, `1500,50` или `1500.50`. Для уменьшения начисления выберите «Корректировка» и введите сумму со знаком минус.
6. В **Документы** загрузите правила для жильцов, затем договоры для подтверждённых размещений. Для восстановления доступа к верному документу после архива загрузите утверждённый экземпляр с корректным получателем.
7. Если нужно сверить прежнюю текстовую запись, в разделе **Размещение** найдите студента по имени. Сопоставьте общежитие, комнату и конкретное место по подтверждающему основанию. Введите его в форму сверки.

## Конкурсный показ

Запустите `npm run demo:dormitory`. Откройте указанный локальный адрес. Используйте отдельные браузерные окна или контексты для ролей. Путь к временным паролям команда печатает отдельно. Учётные данные остаются в игнорируемом каталоге `.local`.

1. Александр открывает **Общежитие → Заселение и переселение**, заполняет заявление и подтверждает данные профиля. Деканат принимает заявление, переводит его в работу и завершает с решением. Комендант выбирает место 1 комнаты 201 в общежитии A, задаёт срок резерва и подтверждает заселение. Мария уже живёт в комнате 201, третье место недоступно.
2. Создайте начисление для Александра с датой оплаты. В кабинете студента проверьте сумму и крайний срок. Перейдите по настроенной ссылке и проверьте журнал. Введите подтверждённую частичную оплату через учётную запись с финансовым назначением.
3. Александр создаёт заявку комнаты, Мария открывает ту же заявку. Комендант принимает её и назначает техника. Техник начинает работу и передаёт результат на проверку. Мария подтверждает выполнение. При необходимости сначала верните результат на доработку и завершите второй цикл.
4. Опубликуйте адресное объявление для общежития A. У Александра и Марии откройте **Новости** и **Уведомления**. У Татьяны, проживающей в общежитии B, проверьте список, уведомление и прямую ссылку.
5. Александр подаёт заявление на переселение. Деканат завершает решение, комендант резервирует второе место комнаты 101 общежития B и подтверждает переселение. Проверьте историю, доступ к новости и ремонтной переписке комнаты 201.
6. Деканат открывает обходной лист. Отметьте применимость проверок в соответствии с учебным сценарием. Сотрудник выдаёт ключ от новой комнаты, студент регистрирует выезд. Комендант принимает ключ, проверяет состояние комнаты и подтверждает выезд после сверки оставшихся начислений. Ответственный за общежитие проверяет обновлённые сведения в обходном листе и принимает решение вручную.
