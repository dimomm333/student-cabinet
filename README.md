# Личный кабинет студента

Конкурсный прототип вымышленного Северного университета на Next.js 16, React, TypeScript и Tailwind CSS 4. Все данные, люди и события вымышлены. Деморежим доступен без регистрации; авторизация, база данных и внешние сервисы не подключены.

## Запуск

```bash
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). В Windows PowerShell с запретом выполнения скриптов используйте `npm.cmd` вместо `npm`.

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
```

Команда `typecheck` генерирует актуальные типы маршрутов и запускает TypeScript без создания JavaScript-файлов. Production-предпросмотр: `npm run build`, затем `npm run start`. В VS Code также есть задача `Student cabinet: dev`, запускающая сервер разработки.

## Что реализовано

- `/` — публичная главная, возможности кабинета, раскрывающиеся новости, вход в деморежим.
- `/dashboard` — боковое меню, верхняя панель, сведения о студенте, занятия на сегодня и завтра, уведомления, новости и быстрые ссылки.
- `/dashboard/[section]` — индивидуальные заглушки всех 13 разделов меню. Неизвестные разделы показывают страницу «не найдено».
- Адаптивная вёрстка, мобильное меню с управлением клавиатурой, видимый фокус и ссылка для перехода к содержимому.

## Структура

- [src/app](./src/app) — страницы, общие макеты и стили.
- [src/components](./src/components) — компоненты интерфейса.
- [src/lib/demo-data.ts](./src/lib/demo-data.ts) — вымышленные данные и описание разделов.
- [public/campus.svg](./public/campus.svg) — локальная иллюстрация кампуса.

Страницы используют App Router. Интерактивные компоненты выделены директивой `use client`. Шрифты системные, иконки и графика локальные; загрузка внешних ресурсов для интерфейса не требуется.
