# Личный кабинет студента

Конкурсный прототип вымышленного Северного университета на Next.js 16, React, TypeScript и Tailwind CSS 4. Все данные, люди и события вымышлены. Деморежим доступен без регистрации.

Подключена локальная SQLite через Prisma. Новости на публичной главной читаются из базы данных. Авторизации, паролей, регистрации и управления аккаунтами пока нет. Пользователи в базе — только начальные вымышленные записи.

## Что потребуется

- Node.js 22.18+ в ветке 22, либо Node.js 24 или 26. Проверено на **Node.js 26.13.0**, npm 11.20.0 и TypeScript 5.9.3.
- npm из комплекта Node.js.
- Отдельный сервер SQLite и системные компиляторы для проверенной Windows x64 не нужны: драйвер поставляется с готовым бинарным пакетом.

Версии `prisma`, `@prisma/client` и `@prisma/adapter-libsql` закреплены на **7.10.1**. У Prisma 8 сейчас статус release candidate, поэтому команда установки без номера версии может выбрать другую ветку. Используйте зависимости из [package.json](./package.json) и [package-lock.json](./package-lock.json).

Документация: [статус выпусков Prisma](https://www.prisma.io/docs/orm/release-status), [SQLite в Prisma 7](https://www.prisma.io/docs/orm/v7/core-concepts/supported-databases/sqlite), [заполнение базы](https://www.prisma.io/docs/orm/v7/prisma-migrate/workflows/seeding).

## Первый запуск

Все команды выполняются **из корня проекта**.

1. Создайте локальный файл окружения из безопасного примера. В PowerShell:

   ```powershell
   Copy-Item .env.example .env
   ```

   Если собственный файл `.env` уже существует, добавьте в него строку вручную, сохранив остальные настройки:

   ```dotenv
   DATABASE_URL="file:./prisma/dev.db"
   ```

2. Установите зависимости:

   ```bash
   npm ci
   ```

   После установки автоматически генерируется Prisma Client. Команда не создаёт и не заполняет базу.

3. Создайте базу и таблицы, затем добавьте вымышленные данные:

   ```bash
   npm run db:setup
   ```

   Эта команда генерирует Prisma Client, применяет сохранённые SQL-миграции и запускает заполнение. SQLite создаст файл `prisma/dev.db` автоматически.

4. Запустите сайт:

   ```bash
   npm run dev
   ```

Откройте [главную](http://localhost:3000) или [кабинет](http://localhost:3000/dashboard). В Windows PowerShell с запретом выполнения скриптов используйте `npm.cmd` вместо `npm`, например `npm.cmd run db:setup`. В VS Code доступна задача `Student cabinet: dev`.

## Как устроена база

SQLite хранит данные в одном локальном файле `prisma/dev.db`. Данные сохраняются между перезапусками приложения. Запускать отдельную программу базы не требуется.

В [prisma/schema.prisma](./prisma/schema.prisma) описаны две модели:

- **User**: идентификатор, имя, уникальный email, роль `STUDENT` или `ADMIN`, дата создания.
- **News**: идентификатор, заголовок, полный текст, дата публикации.

[prisma/seed.ts](./prisma/seed.ts) добавляет двух студентов, одного администратора и три новости. Email используют вымышленный домен `example.test`. Повторное заполнение не создаёт дубликатов, не очищает таблицы и сохраняет отредактированные записи.

Главная запрашивает три последние новости, у которых дата публикации уже наступила. Текст и дата берутся из SQLite; декоративные иллюстрации остаются частью интерфейса. Первый абзац текста служит кратким описанием. Изменения в базе видны после обновления страницы без пересборки сайта. Для пустой базы и ошибки чтения предусмотрены понятные сообщения.

Путь `DATABASE_URL` должен начинаться с `file:`. Относительный путь считается от корня проекта. Миграции, seed и приложение используют один и тот же файл благодаря общему преобразованию пути, в том числе на Windows. Настройки соединения хранятся в `.env`; не задавайте отличающийся `DATABASE_URL` в `.env.local`.

В Git не попадают файлы окружения, сама база, SQLite-журналы и сгенерированный Prisma Client. Безопасный [.env.example](./.env.example), схема и SQL-миграции сохраняются в репозитории.

## Команды базы данных

```bash
npm run db:generate
npm run db:deploy
npm run db:seed
npm run db:status
```

- `db:generate` — обновить типизированный Prisma Client после изменения схемы.
- `db:deploy` — создать базу при её отсутствии и применить уже сохранённые миграции.
- `db:seed` — добавить начальные вымышленные записи.
- `db:status` — проверить, применены ли все миграции.
- `db:setup` — выполнить генерацию, применение миграций и заполнение одной командой.

Когда в следующих заданиях понадобится изменить структуру базы, отредактируйте схему и создайте новую миграцию:

```bash
npm run db:migrate -- --name describe_your_change
npm run db:generate
```

Готовые миграции находятся в [prisma/migrations](./prisma/migrations). Не редактируйте уже применённые миграции. Изменение схемы через `db push` и сброс базы для обычного запуска не нужны.

## Проверки и production-запуск

```bash
npm run lint
npm run typecheck
npm run build
npm run start
```

`typecheck` генерирует Prisma Client и типы маршрутов Next.js, затем запускает TypeScript без создания JavaScript-файлов. `build` также генерирует Prisma Client.

Для production-запуска должна быть подготовлена база: выполните `db:deploy`, а для демонстрационной базы — ещё и `db:seed`. Команда сборки не применяет миграции и не меняет данные. База запрашивается сервером при открытии главной, а не фиксируется в HTML во время сборки.

Локальная SQLite рассчитана на запуск Node.js с постоянным доступом к файлу базы. Этот этап не настраивает облачный хостинг.

## Маршруты и структура

- `/` — публичная главная, возможности кабинета, новости из SQLite, вход в деморежим.
- `/dashboard` — прежний кабинет с боковым меню, занятиями, уведомлениями, быстрыми ссылками и демонстрационными новостями из кода.
- `/dashboard/[section]` — прежние заглушки всех 13 разделов меню.
- [src/app](./src/app) — страницы и макеты App Router.
- [src/components](./src/components) — компоненты интерфейса.
- [src/lib/prisma.ts](./src/lib/prisma.ts) — серверный Prisma Client, повторно используемый при Fast Refresh.
- [src/lib/prisma-client.ts](./src/lib/prisma-client.ts) — создание клиента для приложения и заполнения базы.
- [src/lib/news.ts](./src/lib/news.ts) — запрос опубликованных новостей.
- [src/lib/demo-data.ts](./src/lib/demo-data.ts) — остальные вымышленные данные кабинета.
- [prisma.config.ts](./prisma.config.ts) — конфигурация Prisma CLI.
- [public/campus.svg](./public/campus.svg) — локальная иллюстрация кампуса.

Демонстрационный день кабинета по-прежнему зафиксирован: **11 ноября 2026 года**. Интерфейс на русском языке, поддерживает мобильные экраны. Шрифты системные, иконки и графика локальные.
